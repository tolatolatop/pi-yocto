# Attribution and scope

This compact companion pack is original pi-yocto workflow guidance for the Yocto
Project 5.0 (scarthgap). It is Apache-2.0 licensed. It does not redistribute the
Yocto manuals. `pi-yocto knowledge build` indexes the official documentation and
code from the configured Poky checkout so that every installation uses the exact
local revision.

Upstream sources referenced by these notes:

- Yocto Project documentation in `documentation/`, licensed under Creative
  Commons Attribution-Share Alike 2.0 UK: England & Wales.
- BitBake documentation in `bitbake/doc/`, under its declared documentation
  license.
- OpenEmbedded-Core metadata and classes in `meta/`, under the licenses declared
  in the corresponding source files.

The index records the configured Poky commit and SHA-256 of each chunk. Consult
the indexed source file itself for its authoritative copyright and license text.
